# 半导体研究生就业规划 Skill

**我的模拟电路世界 · Semiconductor Career Planner · v1.1.0**

项目仓库：[https://github.com/jianshengchuanchaun/semiconductor-career-skill](https://github.com/jianshengchuanchaun/semiconductor-career-skill)

给刚入学的半导体、微电子及相关专业研究生，一套从目标岗位倒推的学习工作流：**先知道岗位需要什么技能，再诊断基础，逐步完成学习、项目、验收和求职准备。**

适用于 Codex 与 WorkBuddy。仓库提供同一套技能核心和两个平台适配包；平台规范已核对，客户端导入与对话需按[验收步骤](docs/INSTALL.md#4-五分钟验收能看到名字还不够)检查。本项目不提供就业保证，也不等同平台官方认证。

## 从这里开始

配套阅读：[Word手册与PPT成品获取说明](docs/DOWNLOADS.md) · [逐页讲稿](presentations/10分钟逐页讲稿.md) · [6家企业岗位案例](skills/semiconductor-career-planner/references/company-examples.md) · [从JD到学习计划的示范](examples/company-to-plan.md) · [B站推广文案](docs/BILIBILI.md) · [发布说明](docs/RELEASE.md) · [v1.1验证范围](docs/QA-v1.1.md)。作者本地保留v1.0历史产物。

**源码ZIP不含Word、PPT或PDF成品。** 源码保留手册和演示的内容源、逐页讲稿与构建脚本；32页Word和12页PPT可作为独立Release附件或推广材料另行提供，准确文件名和下载状态见[获取说明](docs/DOWNLOADS.md)。

1. 选平台并按 [安装说明](docs/INSTALL.md) 安装，完整保留参考库和模板。
2. 用下面的提示词开始，先看岗位能力图和基础诊断。
3. 完成第一周任务，把结果反馈给 Skill，调整下一周。

```text
请使用 semiconductor-career-planner 技能。
我是半导体方向研一新生，预计三年毕业，每周能投入12小时。
我想找IC设计相关工作，但还没确定具体岗位。
请先告诉我候选岗位需要具备什么技能，再诊断我的基础。
帮我选择一条主线和一条相邻备选，拆成学期、90天、前4周和今天的行动。
每项任务都写明：怎么学、做什么、花多久、交什么、如何验收。
学校的软件、课题和实习条件请先向我确认，不要假定我有商业EDA。
```

Codex 支持技能选择器的入口可用 `$semiconductor-career-planner`。WorkBuddy 使用已启用的技能并自然语言点名。无法安装时可让宿主读取核心文件，见安装说明中的降级入口。

## 你会得到什么

- **岗位能力地图**：P0基础、P1区分度、P2拓展；目标水平用L0–L4和实际证据表示。
- **个性化差距分析**：考虑课题、毕业要求、已有基础、每周时间、工具与设备资源。
- **可执行路线**：学期总览、90天计划、前4周任务、下一次60–90分钟行动。
- **三级项目**：最小实验、核心项目、可选进阶，附规格、验证、失败诊断和面试追问。
- **持续复盘**：周计划、技能账本、证据索引、求职JD矩阵、面试与转方向策略。
- **企业JD实战拆解**：6家企业官方来源案例，先核届别、阶段和地域，再分清硬要求、加分项、职责与教学建议。

## v1.1 新增：企业要求如何变成学习任务

外企示例包括 NXP 模拟设计校招、Renesas 模拟设计历史实习、NVIDIA 设计与验证实习；中国大陆本土企业示例包括芯朋微模拟校招、泰凌微数字验证校招，以及圣邦微社招成长参照。共6个案例，覆盖模拟设计与数字设计/验证；“本地”在本版指中国大陆本土企业，并非限定某个城市。

| 案例用途 | 需要保留的边界 |
| --- | --- |
| NXP、Renesas、芯朋微：模拟岗位技能拆解 | Renesas明确已过期；芯朋微主要列工作职责，不能补写成硬性资格 |
| NVIDIA、泰凌微：设计/验证岗位对照 | 实习与校招阶段不同；语言、方法学与优先项应逐条判断 |
| 圣邦微：毕业后的成长参照 | 社招要求3年以上经验，不能当作研一或应届入门门槛 |

核查日期为 **2026-09-22**。NXP与NVIDIA目前采用官方招聘域名的搜索索引正文，其动态页直接读取受限；其他样本取得官方正文。没有任何样本被标为“已证实当前仍可投递”。准确日期缺失就留空，学习项目是本项目教学设计，并非企业官方考题或录用标准。详见[案例原始字段与证据](skills/semiconductor-career-planner/references/company-examples.json)。

| 数字物理设计与STA | 应用工程与FAE |

主攻IC设计，覆盖相邻主要方向；一个学生默认只走一条主线和一条相邻备选。RFIC、CIS、功率器件、存储器等细分赛道需要依据具体JD继续展开。

## 设计原则

先告诉学生岗位所需能力，再问关键问题。先用小任务诊断，不假定所有研一都是零基础。每周排定约80%的净时间，保留20%缓冲。看完课不算完成：能独立重做、解释结果和定位失败才是能力证据。优先把课题与求职训练合并，保护毕业进度。

开源仿真、商业PDK仿真、DRC/LVS、后仿、流片和实测分开记录。没有实际证据就不写“通过”“量产”“流片”。没有商业软件时给合法可执行的教学路线，并说明没有覆盖的工业能力。

## 文件结构

```text
skills/semiconductor-career-planner/
  SKILL.md                      技能入口
  references/                   岗位库、资源库、规划与验收方法
  templates/                    学生画像、账本、任务卡、周复盘等模板
docs/                           安装、来源、发布、B站推广、手册内容源
presentations/                  演示内容源、讲稿与构建说明
examples/                       完整案例与示例提示词
evals/                          评测提示与质量检查记录
scripts/                        验证、打包、生成文档
release/                        两个平台ZIP和完整源码ZIP
```

普通使用不需要运行脚本。维护者可在仓库根目录运行 Python 3.10+：

```bash
python scripts/validate_release.py
python scripts/build_release.py
```

生成 Word 需要额外的 `python-docx`；见 [发布说明](docs/RELEASE.md)。普通 Skill 不内置 EDA、实时招聘数据库、联网或后台提醒能力，这些取决于宿主与用户授权。

v1.1修订期间还完成了三个实际模型响应情境，并由另一审阅者逐条核对岗位资格、要求层级、预算和证据边界；详见[行为回归审核及原始响应](docs/behavior-regression-v1.1.md)。三例在本次检查范围内通过，后续资料修订没有按最终全部文件重新生成三例，也尚未完成两个客户端的真实导入验收。成品排版、静态检查与发布包范围见[完整QA记录](docs/QA-v1.1.md)。

## 可直接使用的后续请求

- “我每周只有6小时，帮我缩减为一条能执行的主线。”
- “这是3份校招JD，请提取共同能力，映射到我的项目。”

- “请模拟面试，先问问题，再根据我的答案追问。”
