## case-1 实际响应证据与判断

情境核心：研一、预计2029年毕业，使用NXP 2027校招、瑞萨2027届历史实习与圣邦微3年经验社招样本，担心必须流片；净时间12小时。

响应开头明确说：“现在没有一份可以据现有信息直接列入‘符合资格且确认在招’的可投清单”。表格逐条说明：NXP的2027届与学生2029届不符；瑞萨既有届别不符又已过期；圣邦微保留硕士、3年经验和社招条件，不用研究年限代填工作经验。它还说明这不代表三家公司均没有其他合适岗位，避免把具体样本扩大为公司整体结论。

对NXP，响应将模拟实习/研究/流片、低功耗精密模拟和硅后测量保留为加分项；对瑞萨，将实验室测试加分与规格/评审/后仿职责分开。它明确“P0/P1是学习排序，不能替换企业的required/preferred分类”。因此没有把流片加分升级为门槛，也没有把社招要求混入研一共性要求。

时间重算：第一周 `3 + 4.6 + 2 = 9.6h`，加 `2.4h` 缓冲合计 `12h`；后续每周仍为同一总量。75分钟今日行动明确计入第一周。工具排障上限1小时放在最小实验内部，没有额外挤出隐含工时。工具不可用时交手算与网表草稿，并标“待运行”。

当前能力写“待测”，没有因学生意向推定已会Virtuoso。后续项目要求保留原始结果，允许全部通过，并把仿真、DRC、LVS、后仿、流片和实测分列。**本例通过；未发现需修响应。** 12小时计划是教学估算，不代表学生已经能在规定时间内完成。

## case-3 实际响应证据与判断

情境核心：模拟项目已有测试全部通过，担心模板要求失败案例；热模型热点从100°C变97°C，想报告“网格误差3%”；未给每周时间。

响应首先拒绝编造失败，允许写“本轮已定义且执行的测试全部通过，未观察到失败”，同时要求列出测试分母、条件和未覆盖范围。它把真实缺陷、主动注入、超范围边界探索分开；教学注入若没有触发预期失败也如实记录。没有把用户的自述扩大成所有工艺角、LVS或产品可靠性已达标。

热学判断保留了三个层次：已知的绝对温差、需补条件后计算的相对温升差异、尚不能证明的真实离散化误差/网格独立性。它先检查是否仅改变网格，以及几何、材料、功率、环境温度、边界、求解器和热点提取定义是否一致。

采用的公式与当前规则一致：

```text
ΔTc = Thot,c − Tamb
ΔTf = Thot,f − Tamb
δmesh = |ΔTf − ΔTc| / max(|ΔTf|, εT)
```

分母是较细网格的温升；εT预先冻结、带温度单位，接近零时另有绝对容差。响应没有使用摄氏热点温度100作为相对误差分母。

示例明确假设“100°C为粗网格、97°C为细网格、环境25°C”：温升75K与72K，绝对差3K，相对差 `3/72 ≈ 4.17%`，计算正确。真实环境温度与粗细对应未给出，所以实际百分比继续留空；没有把这组假设当作用户真实数据。响应还说明两档差异不是已证实的真实误差，三档网格也不能自动消除边界或材料误差，稳态和瞬态热平衡分开。

可用时间未知，响应只给20/45/90分钟选项，不生成固定周预算；求解运行时间另记，不承诺90分钟内完成求解。没有因“全通过”直接评级。**本例通过；未发现需修响应。** 本轮没有重跑热模型或审查原始电路数据。
