# 岗位路线库 B：模拟、器件、制造、封装测试与应用

品牌：我的模拟电路世界。版本：1.0。资料核实日期：2026-09-22。

这是规划用的参考库。Agent 只读取学生选定的主线与一个相邻备选方向，不要一次把七条路线布置给一个人。所有项目数值均为本 Skill 设计的**教学验收示例**，不是企业统一录用标准，不是工艺承诺；须在学生确认设备、模型、预算、学制、导师任务后冻结规格。目标岗位的真实要求以当季、当地、具体团队 JD 为准。

目录：0 共同标准；A1 模拟/混合信号；A2 模拟版图；A3 器件/TCAD；A4 工艺/制造；A5 封装/可靠性；A6 测试/产品；A7 应用/FAE；8 生成个人计划；9 来源与限制。

## 0. 阅读规则与共同证据标准

### 0.1 优先级和能力等级

- P0：该路线优先补齐的基础能力；P1：区分度；P2：拓展。初级求职先把 P0 推到 L2–L3，至少一项形成 L3 证据，再发展 P1；这只是学习目标，不代表所有企业相同。企业JD的明确要求和优先项另行记录。
- L0：未接触或无法解释；L1：能讲原理并完成基础题；L2：能参照文档完成最小实验且解释结果；L3：独立完成模块或实验、定位故障、提交可复现证据；L4：在约束下权衡或优化并经复核，不等于资深工程师。
- 表格中的等级是阶段目标。学生当前水平只能由小测、项目文件、日志或现场操作判断，不能由“听过课”“用过软件”推定。
- 周数按每周12–15小时实际排定任务估算，不含正常课程、导师科研和设备等待。个人计划仍只排净时间H的约80%，留20%缓冲：若H为12小时，任务约9.6小时并延长日历。各阶段串联，项目时间已包含在阶段训练中，不能重复相加，也不能把等待设备当作零成本。只有6–8小时/周时先减并行任务，并按实际速度重排。

### 0.2 电路与硬件证据必须分层

| 证据层 | 可以证明 | 不能据此宣称 |
|---|---|---|
| 原理/行为仿真 | 方程、拓扑、控制逻辑和趋势在所用模型内成立 | 达到某量产工艺指标，完成晶体管级 IC 设计 |
| PDK 晶体管级仿真 | 指定模型版本、corner、电压、温度与 testbench 下的性能 | 已完成版图、通过 LVS/DRC、流片成功 |
| 版图验证与寄生后仿真 | 指定 layout/schematic、规则和提取配置下的 DRC、LVS、PEX 与后仿真结果 | 生产签核通过，可靠性合格，实物测量达标 |
| 实物测试 | 指定样品、设备、校准/设置、环境及流程下的测量结果 | 未测条件下必然达标，量产良率或寿命已经保证 |

**Spectre/ngspice 运行成功、Check and Save 无错误都不是 LVS 通过。** LVS 必须有专用检查器、被比较的版图与原理图/网表、规则版本、完整报告和最终匹配结论；DRC、ERC、天线规则、EM/IR、PEX 各自独立。报告有 waiver 时写“含经批准豁免”，不能写“零错误”。无实际签核流程与授权不能自称完成 foundry signoff。原理仿真和物理验证的分工可参见 [Cadence 官方说明](https://support1.cadence.com/public/docs/content/20514747.html)。

每个项目必须保存：`spec.md`、来源/许可说明、环境与版本、可运行输入、原始结果、指标提取方法、通过/失败矩阵、真实失败分析或明确标注的教学故障实验（全部通过也如实记录）、个人贡献、复现入口。对外只发布有权公开的内容；PDK、模型、规则文件、导师/企业数据不能随 GitHub 项目泄露。涉及实验设备时遵守实验室准入与操作规程；无准入就选择仿真或公开数据支路。

## A1. 模拟 / 混合信号 IC 设计

### 岗位与适配

最终岗位：模拟 IC 设计工程师、混合信号设计工程师；后续细分为电源管理、数据转换器、时钟/PLL、接口或传感器前端。不要把这些细分方向全选。研一先用一个 OTA/比较器项目判断是否喜欢持续分析、调参、查工作点和处理规格取舍。

典型交付物：模块规格、架构与误差/噪声预算、晶体管原理图、testbench、PVT/统计验证矩阵、版图约束、后仿真报告、测试计划。适合愿意手算、能接受迭代、对电流电压和物理机制有兴趣的人。若只喜欢画 PCB，先试应用路线；若更喜欢空间结构与连线，试模拟版图。无商业 EDA 不等于不能开始，但需要清楚展示已完成的证据层。

### 技能—等级—证据

| 优先级 | 技能与目标 | 可检查证据 |
|---|---|---|
| P0 | MOS 工作区、gm/ro、体效应、寄生电容；L2–L3 | 手算一个偏置点；扫 ID–VG/ID–VD；解释与模型偏差；单位完整 |
| P0 | 小信号、差分对、电流镜、反馈与补偿；L3 | 从电路推到增益/极点的简化模型，再与 AC 和瞬态交叉验证 |
| P0 | DC/AC/transient/noise 仿真、日志阅读；L3 | 独立建立 testbench，定位一次浮空/偏置/收敛/测量窗口错误 |
| P0 | 规格分解和 PVT 验证；L2–L3 | 每个指标对应刺激、测量公式、条件与 pass/fail，失败 corner 不遗漏 |
| P1 | 失配、Monte Carlo、输入噪声、PSRR/CMRR；L2–L3 | 区分 process 与 mismatch；说明模型支持与种子/样本数，附统计不确定性 |
| P1 | 版图可实现性、寄生回标；L2 | 与版图伙伴完成一次约束交接；比较 pre/post 差异并归因 |
| P1 | Python/脚本批处理；L3 | 自动生成指标表，随机抽三点手动复核一致 |
| P2 | ADC/PLL/LDO/SerDes 等单一细分；L2；优化目标可到 L4 | 一项独立子模块，含系统预算和至少两个取舍方案 |

### 前置依赖与学习步骤

依赖链：电路分析与复数/拉普拉斯基础 → MOS 和偏置 → 小信号 → 反馈/稳定性 → 噪声与失配 → 指标驱动设计 → 版图约束/后仿真。先修不足先补前两段，不要靠背结论跳到 PLL。

1. 第 1–3 周：完成 MOS、镜像源和共源级的手算与仿真；每周只交三张图及其推导。验收：换一个负载/偏置后能先预测方向再仿真。
2. 第 4–7 周：差分对、单级 OTA、单位增益反馈；把开环增益、闭环带宽、压摆率和稳定性分开。验收：能解释大信号与小信号响应为何不同。
3. 第 8–15 周：完成核心项目；每两周冻结一次规格表和失败列表。先 nominal 成立，再拓展 corner，避免用盲目扫参掩盖结构错误。
4. 第16–23周：选择统计验证或版图后仿真之一深化，资源足够再做两者。验收：解释不同条件下实际得到的结果差异，优先复盘真实失败；若原规格范围全部通过，应如实记录，可另做明确标注的教学故障注入或边界探索，不能伪装成真实失败corner。
5. 第 24–28 周：向细分岗位靠拢，准备 10 分钟设计讲解与一个现场重现任务。三年制可把研二课题深化为进阶项目；两年制以核心项目完整交付优先。

### 三级项目

**最小项目：五管 OTA 或单级差分放大器（2–3 周）。** 选合法模型，VDD 在模型额定范围内，先固定一个偏置与负载。教学目标：DC 增益 ≥30 dB、负反馈工作、输出不削顶的输入范围明确。提交工作点、手算、AC、小信号阶跃四类证据；在手算适用区，增益估算与仿真偏差目标 ≤30%，超出必须解释而非删除。故障诊断顺序：供电与体端 → 支路电流与饱和区 → 共模/输出范围 → 测量节点和激励 → 模型/数值设置。通关不是只截一条增益曲线。

**核心项目：两级补偿 OTA（6–8 周）。** 可行的示例规格：适配 1.8 V 器件的 PDK 下，VDD=1.8 V、CL=2 pF、nominal 增益 ≥60 dB、UGB ≥5 MHz、相位裕度 ≥60°、静态功耗 ≤1 mW；实际器件不适合时先重定规格。先做 gm/电流/电容预算，再建立开环和闭环 testbench；明确环路断点与偏置保持，不能从闭环相位直接读相位裕度。冻结电源范围、温度范围与 PDK 可用角后逐项验证，只有已跑过的条件可标通过。教学验收：nominal 达标，验证矩阵完成率 100%，每项失败有原因或后续动作；“全部 corner 达标”与“完成了 corner 检查”分开计。作品集包含补偿前后对比、真实失败或单独标记的教学故障注入，以及设计改动与回归。原规格矩阵全部通过也如实保留，不强求某个工艺角失败。

**进阶项目：任选一条（8–12 周以上）。** ① OTA 版图—DRC/LVS—PEX—后仿真，预先设定如 UGB 下降 ≤20%、PM ≥55°的教学预算并解释超标寄生；② 一个 8-bit、1 MS/s 级别 SAR ADC 的行为预算与比较器/CDAC 子模块，行为仿真与晶体管实现分栏；③ LDO 在明确负载、电容和 ESR 范围下的稳定性及瞬态。需要报告 PPA/噪声/精度取舍，保留真实失败。没有统计模型时只做参数敏感性，不命名“工艺失配 Monte Carlo 良率”；没有实物时不写“芯片测试成功”。

### 面试、误区与降级

面试练习：不用 PPT 画出信号与偏置路径；解释提高 gm 的代价；解释为何 AC 稳定而大信号有长恢复；用一个真实失败或明确标记的教学故障做 5 分钟根因说明，原测试全部通过则如实说明；现场解释一个测量表达式。常见误区：背书目替代设计、只测典型点、把报错消失当电路正确、抄电路而没有规格预算。

无商业工具：使用 ngspice 或 LTspice 学原理；只有运放宏模型时只能证明板级/行为结论。合法开源 PDK 可用于指定流程练习，但不能等同目标公司先进节点经验。缺流片时写“完成 PDK 仿真/版图后仿真”，用失败诊断、复现包和预算展现能力。建议资源：R1、R2、R3、R4、R5。

## A2. 模拟版图

### 岗位与适配

最终岗位：模拟版图设计工程师、定制版图工程师；可能覆盖模拟、混合信号、存储器定制单元。交付物：层次化版图、匹配/隔离/走线约束实现、DRC/LVS 报告、寄生提取、ECO 与版本记录。适合重视细节、喜欢空间布局、愿意反复核对电路连接与几何约束的人。版图不是“把线连上”，也不能把对称外观当作电学匹配证明。

### 技能—等级—证据

| 优先级 | 技能与目标 | 可检查证据 |
|---|---|---|
| P0 | MOS/电阻/电容的版图结构、体端与网络识别；L2 | 从原理图逐个映射实例、参数、端口和版图器件 |
| P0 | 工艺层、间距/包围/密度等规则阅读；L2–L3 | 解释五类真实 DRC 错误；记录 rule ID、坐标和修复前后 |
| P0 | 电流镜/差分对匹配、指状化、dummy；L2–L3 | 给出器件拆分表、中心位置、方向/环境和连线策略 |
| P0 | DRC 与 LVS；L3 | 同一最终版本有独立报告；故意引入再定位一个开路/短路/参数错配 |
| P1 | PEX、敏感节点、屏蔽/隔离、寄生预算；L2–L3 | 关键网 R/C 排名、前后仿真差异与 ECO 证据 |
| P1 | 电源路径与可靠性规则意识；L2 | 依据工艺规则和电流约束说明布线，不凭经验捏造允许电流密度 |
| P2 | SKILL/Tcl/Python 自动化、层次复用；L2；约束优化可到 L4 | 生成/检查脚本与人工抽查记录；比较面积和关键寄生的取舍 |

### 前置依赖与学习步骤

依赖链：电路图/器件端口 → 工艺层和合法器件 → 基础 DRC/LVS → 匹配与布局 → 模块布局 → PEX/ECO。

1. 第 1–3 周：画单管、反相器和电阻，读规则，建立每次运行的版本清单。验收：能够从 LVS 提取结果找到对应原理图实例。
2. 第 4–6 周：电流镜和差分对，先写约束再画图。每种匹配方式必须说出适用梯度和不解决的问题。
3. 第 7–13 周：完成核心 OTA 版图，先 floorplan、pin、供电/体端，再关键器件、关键网、其他网，最后检查密度等要求。
4. 第 14–20 周：PEX 与 ECO，比较关键寄生和性能；把两次修复形成案例。高阶节点经验要在合法环境中补，不能通过修改图片获得。

### 三级项目

**最小项目：1:1 电流镜 + 匹配差分对（2–3 周）。** 规格：器件尺寸、支路比例、端口、well/tap、dummy 连接明确，所有目标器件映射率 100%。量化验收：在选定规则集下零未处理 DRC，LVS 匹配；统计两支关键走线长度/提取 R/C 差异，先冻结如 ≤10% 的教学目标。若差异不达标解释负载与约束，不能仅靠视觉对称判定。失败排查：pin label → 体端/电源全局网 → 开短路 → finger/倍乘参数 → 提取器件类型。证据包括连接映射表和故障注入前后报告。

**核心项目：独立完成五管或两级 OTA 版图（6–8 周）。** 规格：使用已冻结的晶体管级原理图，列出差分输入、镜像节点、补偿节点与供电的约束；面积上限由器件总面积和合法间距估计，不硬套先进节点数字。验收：最终 DRC/LVS 状态清晰，PEX 可回标；同一 testbench 比较 gain/UGB/PM/power，列出每项 pre/post 差值与预算是否满足。只提取了 C 时不能写完整 RC 后仿真。作品集：floorplan、敏感网标注、最终版图、报告摘要与可追溯运行 ID、两条 ECO 解释。

**进阶项目：带隔离和层次接口的模拟子模块（8–12 周）。** 选比较器/偏置网络/运放之一，增加版图边界、pin、shield、guard ring 和复用要求；依据真实 PDK 检查 ERC/天线/密度等可用规则。量化验收：相对基线在不破坏 DRC/LVS 与关键电性能的前提下减少面积或关键寄生，例如选一个 ≥10% 改善目标；必须披露其他指标变化。未达成改善也可成为有效取舍分析，不能隐藏回退。需由另一位同学或导师按相同输入复核。

### 面试、误区与降级

练习：解释 common-centroid 的假设与限制；为何几何对称却电学不对称；一次 LVS 参数不匹配如何逐层定位；区分 guard ring 与信号屏蔽；说明 PEX 后慢在哪里。误区：只交彩色版图截图、把 rule waiver 删除当修复、把 DRC clean 当 LVS clean、把教学 rule deck 当量产签核。

无 Virtuoso 可尝试合法开源 PDK 对应的 Magic/Netgen 等兼容流程，先验证工具与规则确实配套。只会 KLayout 绘图/查看而未配置器件提取和 LVS，不得宣称完成完整流程。若规则/提取缺失，交几何与连接设计练习，等级停在对应 L1–L2，不伪造报告。建议资源：R4、R5。

## A3. 器件 / TCAD / 器件建模

### 岗位与适配

最终岗位：器件工程师、TCAD 工程师、器件建模工程师；需按 JD 区分器件开发、工艺建模、紧凑模型提取。交付物：结构/网格/物理模型输入、求解和收敛记录、I–V/C–V 与参数提取、模型校准/验证、敏感性分析、设计建议。适合喜欢物理机制、数学和数据、愿意检查单位与数值收敛的人；“跑出一张云图”不足以证明能力。

### 技能—等级—证据

| 优先级 | 技能与目标 | 可检查证据 |
|---|---|---|
| P0 | 能带、载流子统计、PN 结、MOS、漂移扩散；L2 | 用能带和边界条件解释两种偏置状态，完成数量级估算 |
| P0 | 网格、边界/接触、材料和物理模型选择；L2–L3 | 一份模型启用理由表；至少三档网格的收敛对比 |
| P0 | DC 扫描、求解收敛与异常诊断；L3 | 原始 log、bias sweep、失败点与重试策略，不能抹掉失败点 |
| P0 | Python 数据清理、Vth/SS/DIBL 等提取；L2–L3 | 公式、区间、单位、方法一致性与手工复核 |
| P1 | 测量数据校准、参数可辨识性、保留集验证；L2–L3 | 训练/验证条件分离；拟合残差、误差定义与不确定性 |
| P1 | 工艺—结构—电性关联；L2 | 一个结构或工艺参数变化的因果假设与反例 |
| P2 | 功率器件、存储器、辐照、量子输运或紧凑模型之一；L2；约束研究可到 L4 | 针对单一问题的模型选择、敏感性与外推边界 |

### 前置依赖与学习步骤

依赖链：半导体物理 → PN/MOS 解析近似 → 数值与单位 → TCAD 基准 → 提取与收敛 → 数据校准。工艺仿真生成结构与器件仿真求电性是不同任务；[Synopsys 官方 TCAD 概览](https://www.synopsys.com/manufacturing/tcad.html)用于核对工具范围，不是免费授权入口。

1. 第 1–4 周：手算 PN 结与 MOS 电容；建立单位表，完成对数坐标和微分提取练习。
2. 第 5–8 周：从官方示例复现 PN 结/MOS，不急于复杂异质结；做网格、偏压步长和初值敏感性。
3. 第 9–16 周：MOS 核心项目，做短沟道指标与趋势解释。输出重点是可复现曲线和提取，不是美化云图。
4. 第 17–24 周：有合法测量数据则校准；无数据则做参数敏感性和解析/数值交叉验证，明确未校准。
5. 第 25–30 周：根据目标 JD 选择一个器件类型，完成 10 分钟“参数改变为何导致指标变化”的演示。

### 三级项目

**最小项目：一维 PN 结（2–3 周）。** 冻结材料、掺杂、温度、接触和扫描范围；先估计内建势/耗尽宽度。验收：平衡电势与低偏解析近似趋势一致；在近似适用区选择耗尽宽度或电势作为比较指标，教学相对差异目标 ≤10%；三档网格关键指标变化目标 <2%。偏差必须区分解析假设、边界与数值问题。证据：输入 deck、网格、log、I–V、解析对比及单位检查。

**核心项目：二维 MOSFET 参数与短沟道效应（6–8 周）。** 冻结结构和模型；至少三个栅长、两个漏偏、两档温度（全部在模型适用范围内），共 12 条或以上 ID–VG 数据；Vth/SS/DIBL 使用同一提取定义。验收：每个结果可追溯至输入组合；细化网格后关键指标变化目标 <3%；DIBL 在相同提取方法下比较，SS 不从任意区间拟合。故障排查：长度/浓度单位 → 接触/边界 → 初值和步长 → 网格 → 模型适用性；禁止仅调求解容差使非物理解“通过”。作品集应包含一个关键趋势的假设、检验和替代解释；若出现反直觉结果，再记录核查过程，不强求得到异常趋势。

**进阶项目：测量校准与保留条件预测（8–12 周）。** 用自测或有许可的公开数据，先登记来源、温度、器件尺寸、误差；选少量具有物理含义的参数，避免同时自由拟合全部参数。冻结如 log-ID RMSE ≤0.15 decade、Vth 偏差 ≤30 mV 等教学目标，仅在明确电流范围与测量底噪上方评估；低于底噪的数据不当成准确值。保留一组 VDS/温度/尺寸用于验证，分别报告训练和验证误差。无测量数据时可以用合成数据验证校准程序，标题必须写“合成基准”，不能声称真实工艺已校准。

### 面试、误区与降级

练习：网格变细为什么不总意味着真实；如何选择迁移率/复合/量子修正；提取法不同为何 Vth 不同；拟合很好为什么外推失败；process simulator 与 device simulator 的职责。误区：默认参数都当真实工艺、把二维切面当三维精确结果、用论文截图手抄数据却不说明误差、AI 自动修改 deck 而不懂模型。

无 Sentaurus/Silvaco 授权：用 [DEVSIM 官方资源](https://devsim.org/)或自写一维方程做器件数值训练，明确其模型/维度范围；这能证明物理和数值能力，不能自称熟练商业全流程。无实验设备：使用许可清晰的公开曲线，记录数据出处和提取误差；没有真实数据就保留“尚未校准”字段。建议资源：R1、R6、R7。

## A4. 工艺整合 / 单模块工艺 / 制造

### 岗位与适配

最终岗位至少分开看：**PIE（Process Integration Engineer）**关注跨模块流程、器件电性、良率与问题协同；**PE（Process Engineer）**通常聚焦光刻、刻蚀、薄膜、扩散、CMP 等具体模块的工艺窗口、变异和异常控制。设备工程 EE 的机台维护/效率职责又不同。不同企业的缩写可能不同，应读职责。上述区分可参考 [TSMC 官方角色说明](https://www.tsmc.com/static/english/careers/campus_recruitment_2025/index.html)，该页是岗位职责资料，不代表 2026 年本地仍有该招聘名额。

交付物：流程与关键参数图、split/DOE 方案、SPC 与量测分析、异常隔离和根因验证、改善前后数据及变更记录。适合重视现实约束、愿意做数据与实验、能与多团队协作的人。洁净室、值班、轮班、工作地点需逐个核实 JD 并由学生自行评估，不把任何岗位都描述成固定工作制。

### 技能—等级—证据

| 优先级 | 技能与目标 | 可检查证据 |
|---|---|---|
| P0 | CMOS 制程主线和关键模块；L2 | 自画剖面演变并标出一次工艺变化可能影响哪些电学指标 |
| P0 | 统计、分布、置信区间、相关与因果；L2–L3 | 一个保留时间/机台/批次字段的分析；不把同批重复点当独立样本 |
| P0 | SPC、控制界限与规格界限区分；L2–L3 | 先检查稳定性再讨论能力；保留异常点并作分类 |
| P0 | DOE 与问题分解；L2–L3 | 明确因素、响应、随机化/阻断、重复与确认实验 |
| P0 | 量测误差、数据血缘、实验室 EHS 认知；L2 | 量测流程和仪器/样品记录；无授权不操作机台 |
| P1 | PIE：跨模块电性/良率关联；L3；PE：某模块窗口；L3 | 一份假设—证据—排除—确认链，说明自己负责的范围 |
| P1 | Python/SQL、批次/wafer/site 分析；L2–L3 | 可重跑的清理和图表，缺失/异常处理有审计记录 |
| P2 | FDC、APC、缺陷图分类或 TCAD 工艺联动；L2；确认改善可到 L4 | 与简单基线比较、跨批次验证、避免数据泄漏 |

### 前置依赖与学习步骤

依赖链：制程与量测 → 数据结构/统计 → SPC → DOE → 模块实验/跨模块追因。器件物理基础弱的 PIE 学生需补 MOS；PE 学生应根据模块补材料、化学、等离子体或热过程。

1. 第 1–3 周：画 CMOS 流程、选择一个模块，整理输入—输出—量测—常见失效关系。
2. 第 4–7 周：统计与 Python，先做数据字典与清理，再画图；做一次量测重复性练习。
3. 第 8–12 周：SPC 与最小异常定位；把统计异常和规格不合格分别标出。
4. 第 13–20 周：DOE 核心项目；PIE 加跨模块电性关联，PE 加工艺窗口。实验资源不足就明确使用公开/合成教学数据。
5. 第 21–26 周：把项目压缩成问题单与改善报告，尝试与课题组合法实验或实习衔接；不在个人电脑上模拟成“做过量产”。

### 三级项目

**最小项目：制程波动诊断（2–3 周）。** 使用公开或自行生成并清晰标记的 100–300 条数据，含日期、批次、机台、量测值和单位。规格：检测预先声明的均值漂移/方差变化，不知道异常标签时保留盲测集。验收：清理规则可追踪，三类异常案例有解释，控制界限来自合理基线；合成标签存在时报告 precision/recall 而非只展示漂亮图。故障排查：单位/重复记录 → 量测变化 → 批次混合 → 时间顺序 → 工艺假设。作品集包括数据字典、异常清单与一页分析。

**核心项目：单模块 2³ 因子实验 + 确认（6–8 周）。** 教学示例选择薄膜厚度/刻蚀深度的响应，三个因素、八种组合；重复数与中心点按资源和噪声设定，不能把一次仿真复制成实验重复。验收：因素主效应/交互作用解释、残差检查、随机化/阻断说明、至少三个未参与拟合的确认点；示例目标为确认点误差 ≤10%，但必须在项目前定义响应的合理量纲和尺度。未通过时检查混杂、漂移、量测系统和模型形式。无机台支路只能称 DOE 分析练习。真实危险化学/工艺配方只在实验室规程下执行，本 Skill 不提供可直接操作的危险配方。

**进阶项目：PIE 良率问题闭环或 PE 工艺窗口（8–12 周）。** PIE：把某电性分布恶化与两个工艺假设关联，分离产品/机台/批次，设计能区分假设的实验；PE：在两个相互制约的响应下确定窗口。量化验收：基线与改善定义一致，使用独立确认批次或明确模拟保留集，报告效应量和不确定性；不把 10%→8% 的坏品率写成提升 2% 的良率而不注明百分点。真实量产结论需要真实数据、实际执行、授权披露和复核，缺一就按教学分析说明。

### 面试、误区与降级

练习：Cp 高而 Cpk 低意味着什么；工艺不稳定为何不直接报 Cpk；相关性最强为何不一定是根因；如何区分量测漂移和工艺漂移；PIE 与 PE 如何分工。误区：删除所有 outlier、用规格线当控制线、混合机台算一个平均值、将机器学习准确率等同改善良率。

无 fab 权限：把流程理解、统计脚本和 DOE 设计做到可复核，并通过课程实验/校内平台争取真实量测经验；不能承诺获得机台或绕过准入。公开数据和合成数据能证明分析能力，不能证明调机或工艺导入经验。建议资源：R8、R9、R6。

## A5. 封装 / 可靠性 / 失效分析

### 岗位与适配

这是关联岗位族，不应一开始全学：封装设计关注结构与电/热/机械协同；封装工艺关注装联流程与良率；可靠性关注失效机制、应力试验与寿命证据；失效分析 FA 关注定位和根因证据。最终先选一个主岗位，再补相邻知识。交付物包括模型与边界条件、封装方案、试验矩阵、失效记录、统计与结论；FA 还需样品链路、定位证据与替代假设排除。

适合材料、机械、热学或器件基础较好且愿意做交叉验证的人。电路学生可以从热/电寄生切入；材料学生可从界面/应力/失效机制切入。不要把“跑有限元”当作完成可靠性认证。

### 技能—等级—证据

| 优先级 | 技能与目标 | 可检查证据 |
|---|---|---|
| P0 | 封装结构、材料、互连、工艺基础；L2 | 带结构/材料/关键界面的一页剖面图及三个风险假设 |
| P0 | 主线基础：热传导/应力/电寄生或失效机制；L2–L3 | 解析数量级与仿真/实验交叉检查，说明边界条件 |
| P0 | 实验设计、样本/失效定义、可追溯记录；L2–L3 | 试验前冻结判据；样品编号、应力与失效时间完整 |
| P0 | 不确定性、删失数据、寿命推断边界；L2 | 区分仍未失效和失效时间未知，不把零失效当无限寿命 |
| P1 | 有限元或热 RC 模型、网格独立性；L3 | 三档网格/离散化比较，能量/单位检查和敏感性 |
| P1 | 可靠性计划/FMEA/FA 证据链；L2–L3 | 应力—失效机制—测量—判据对应表，排除至少两个替代原因 |
| P2 | SI/PI、电热耦合、先进封装或加速模型；L2；优化可到 L4 | 单一耦合问题，参数来源与适用范围明确，复核取舍 |

### 前置依赖与学习步骤

依赖链：结构材料 → 基础物理/量测 → 模型与假设 → 可验证实验 → 可靠性统计或结构优化。

1. 第 1–3 周：看懂一种 QFN/BGA 等封装剖面和装联流程，确定主线。
2. 第 4–7 周：热 RC/热阻或应力基础，做解析和数值对比；可靠性主线同时补概率与删失数据。
3. 第 8–15 周：核心项目，首先冻结边界、材料参数和可验证量，避免模型过于复杂却无法校核。
4. 第 16–23 周：做结构改进/敏感性，或设计可靠性验证计划；有校内设备再做规范测试。
5. 第 24–28 周：将一个失效案例写成假设、证据、尚缺证据和后续实验，准备工程汇报。

### 三级项目

**最小项目：热路径与量纲审计（2–3 周）。** 根据公开器件资料选一个封装/板级场景，计算功率和简化温升；明确环境温度、散热边界、PCB 条件。验收：手算与同假设热 RC 数值解偏差目标 <5%，能说明 θJA 与 ψJT 等量的不同用途，不能把数据手册 θJA 当任何 PCB 的常数。证据是模型、参数来源和适用边界，不是声称实物结温已验证。参考 [TI 封装应用资料入口](https://www.ti.com/design-development/packaging/smt-application-notes.html)。

**核心项目：封装/板级热模型或可靠性数据分析（二选一，6–8 周）。** 热支路：固定一种结构、两个功率和三个散热条件，三档网格；稳态教学验收定义为能量平衡误差 |P_in−P_out|/max(|P_in|, ε_P)<2%，网格差异用温升ΔT=T_hot−T_amb计算：|ΔT_fine−ΔT_coarse|/max(|ΔT_fine|, ε_T)<3%；项目前冻结ε_P、ε_T及接近零时的绝对容差，并记录绝对温差(K)。瞬态需另计储能，不能套稳态平衡式。若有测温则列传感器误差/接触影响及偏差，不能以壳温直接冒充结温。统计支路：使用有来源且含删失标记的数据（合成则标明），比较非参数生存曲线与选定分布模型；验收为删失处理正确、参数/置信区间可复现、保留条件检查、零失效样本的推断限制写清楚。失败诊断先查输入/单位/边界/删失，再讨论物理机制。

**进阶项目：结构改进 + 可靠性验证计划（8–12 周）。** 教学目标任选：相同功耗/边界下峰值温升下降 ≥10%，或降低已定义应力集中指标；同时报告面积、材料、可制造性代价。可靠性主线可改为失效机制驱动的验证计划：每项说明应力、监测、判定、样本选择依据、资源和证据缺口。没有真实执行不能写“通过 HTOL/温循/HAST/AEC 认证”；未取得当前标准正文时不得编造试验时长、温度或样本量。高温高压/高湿/破坏性分析需实验室资质与监督。

### 面试、误区与降级

练习：热阻表中的数能否直接套用；更细网格为何不解决错误边界；Arrhenius 外推需要哪些机制假设；零失效说明什么；外观裂纹与电失效如何建立证据关联。误区：无材料来源的彩色云图、有限元收敛等于物理验证、把相关失效点当根因、用合成寿命数据声称产品可靠。

无商业有限元：使用可检查的热 RC/解析模型或有合法许可的求解器进行方法训练；无扫描声学/SEM/温箱/应力设备：做公开案例的证据重建和试验设计，保留未验证字段。标准条款、版本和授权需逐次核实；一般网页只能作为入口。建议资源：R8、R10、R11。

## A6. 测试 / 产品 / 表征验证

### 岗位与适配

最终岗位细分：测试工程师关注测试程序、覆盖率、测试时间与硬件；产品工程师关注产品导入、良率、分档和跨部门闭环；表征/验证工程师关注器件在工作条件下的规格、边界和异常。具体组织常有重叠，以 JD 为准。交付物：测试计划、限值与单位、自动化程序、治具/连接图、原始数据、校准/不确定性说明、良率/异常分析。

适合喜欢动手、写脚本、追故障、愿意核查数据可信度的人。模拟/数字背景均可进入，但不能把仿真 testbench 等同使用过 ATE；也不能把接通示波器等同完整表征。

### 技能—等级—证据

| 优先级 | 技能与目标 | 可检查证据 |
|---|---|---|
| P0 | 读数据手册、把规格转成测试项；L2–L3 | 每项有刺激、量程、采样、限值、单位、环境和异常动作 |
| P0 | 电源/示波器/DMM/信号源基础与接线；L2 | 真实设备与探头设置记录，理解地线、输入阻抗和带宽限制 |
| P0 | Python/数据处理/仪器通信；L3 | 一次可重复执行的 sweep、数据落盘、超时与错误处理 |
| P0 | 误差、重复性、pass/fail 和边界；L2–L3 | 手动与自动结果对照、单位/空值/饱和数据检查 |
| P1 | ADC/DAC/电源/数字接口某类器件表征；L3 | 静态与动态指标在指定条件下的完整原始数据 |
| P1 | 良率/binning、异常定位、测试时间；L2–L3 | 基线与优化结果，在覆盖和准确性不退化时比较时间 |
| P2 | ATE 平台、相关性、多 site、DFT 接口；L2；权衡可到 L4 | 只有真实访问/课程平台记录才标具体 ATE 实操 |

### 前置依赖与学习步骤

依赖链：电路与 datasheet → 手工测量 → 误差/量程/单位 → 自动化 → 覆盖/统计 → 产品闭环。数字 ATE 路线需加时序、pattern 与基础 DFT；模拟测试路线需加采样/FFT/噪声。

1. 第 1–3 周：选择可获得的低压评估板/已有器件，整理五个关键规格；先做一项手工测量和误差估计。
2. 第 4–6 周：学习 Python 与仪器通信，做 mock 测试，再接真实设备；未经核实不自动发送可能改变电压/输出的命令。
3. 第 7–14 周：完成核心项目，覆盖正常、边界、通信失败和数据异常。
4. 第 15–21 周：做测量相关性、重复性和测试时间优化；学会区分 DUT、治具、仪器与脚本问题。
5. 第 22–26 周：做产品问题单，形成 10 分钟“从错误数据到根因”的演示，按 JD 补 ATE 或器件专题。

### 三级项目

**最小项目：自动化 DC 扫描（2–3 周）。** 选实验室允许的低压器件，先冻结供电/限流/输入范围；或在 mock 仪器上训练同接口。规格：10 个设定点×3 次重复，记录时间、设备 ID、设定值、读回、单位和状态。验收：30 条结果可追踪，手工抽查三点，误差落在预先定义的仪器与系统预算；断连/超时可安全退出并标明不完整。mock 结果必须标为仿真数据。作品集含接线图、操作规程、raw CSV 与故障演示。

**核心项目：一个 ADC/电源芯片的表征（6–8 周）。** ADC 示例：选择已有 12-bit 级评估板，测 DC transfer、重复性以及在设备满足条件时的 SINAD/ENOB；采样率、输入频率/幅值、窗函数/相干采样、样本数、源纯度必须登记。验收：静态/动态脚本先用已知合成信号验证；再对实测数据给指标和误差边界；至少 3 个输入条件，每个 ≥3 次重复。若源和采集链不足，仅提交静态测试，不编 ENOB。电源支路可用负载调节/效率/启动作为三项指标，负载范围必须按实验室规程。失败先查接线/供电 → 量程和采样 → 数据格式/时钟 → 治具 → DUT。

**进阶项目：相关性与测试效率（6–10 周）。** 同一 DUT 用两种测量路径或手动/自动流程，冻结限值和样本；量化偏差、重复性、边界误判及测试时间。教学目标可为总执行时间下降 ≥20%，但要求有效覆盖不减少、结果偏差在预算内、失败可追踪。无真实 ATE 时仅写 bench 自动化优化；无多颗样品时不称批量良率结论。作品集包含优化前后相同输入对比、失败 bin 与复测规则。

### 面试、误区与降级

练习：测得 ENOB 低先查什么；如何区分 DUT 噪声和信号源噪声；量程如何影响误差；测试限值与 datasheet 规格是否相同；为何复测后良率提高可能只是筛选偏差。误区：忽略探头负载、自动舍弃失败、把脚本无异常当测量可信、用一颗器件推断量产分布。

无设备：先做仪器 mock、数据格式/FFT/限值判断和异常注入，形成软件验证证据；随后争取校内共享设备或实习，不必先购买昂贵仪器。无 ATE 授权：保留 bench 与软件能力，不能伪造平台经历。建议资源：R3、R8、R12、R13。

## A7. 应用工程 / FAE

### 岗位与适配

最终岗位：应用工程师 AE、现场应用工程师 FAE、技术支持/方案工程师。AE 往往更侧重产品应用、评估板与参考方案，FAE 更侧重客户需求澄清、系统选型、现场问题和反馈；实际分工因公司而异。可参考 [TI 官方 FAE 工作介绍](https://www.ti.com/video/6351499567112)。交付物：需求和约束、选型对比、误差/功耗预算、原理图/BOM、验证结果、问题复现包、面向客户的技术说明。

适合愿意沟通、喜欢从系统问题连接到器件细节、能清楚表达限制的人。沟通不是只会说话，核心是准确理解需求、用证据缩小问题、推动验证。是否出差及频率必须看具体岗位，不把 FAE 一律等同销售，也不把 AE 一律等同 IC 设计。

### 技能—等级—证据

| 优先级 | 技能与目标 | 可检查证据 |
|---|---|---|
| P0 | 模拟/数字接口基础、datasheet 阅读与选型；L2–L3 | 两个候选器件的条件一致比较，区分 typical/max 与绝对最大额定 |
| P0 | 需求澄清和预算；L3 | 把“精度高/速度快”改成量程、带宽、误差、供电、成本等可测约束 |
| P0 | 仿真、板级调试与测量；L2–L3 | 一次最小复现，原始波形、接线、设置、假设排除完整 |
| P0 | 技术写作/演示和跨团队沟通；L3 | 一页应用说明，5 分钟演示，问题单中区分事实/假设/待确认 |
| P1 | PCB 回流、去耦、保护、稳定性/EMI 基础；L2–L3 | 设计检查表与两项实际问题修复证据 |
| P1 | 某类系统：电源/传感器/采集/电机/接口；L3 | 从需求到可验证方案的端到端项目，不只拼模块 |
| P2 | 固件、脚本、行业场景与英文会议；L2；权衡可到 L4 | 客户式变更题、英文邮件草稿、自动化演示；不擅自发送给真实客户 |

### 前置依赖与学习步骤

依赖链：电路基础 → 数据手册/误差预算 → SPICE → 原理图/测量 → 最小复现 → 方案比较与沟通。以系统问题牵引学习，不先背几百个型号。

1. 第 1–3 周：选一个低压传感/采集场景，写需求和两个器件的选型表；查“保证值在哪些条件成立”。
2. 第 4–7 周：运放输入/输出范围、带宽、噪声和稳定性，学一节就改一次电路；记录一次错误选型如何暴露。
3. 第 8–15 周：核心前端项目，先仿真，再用已有板/设备验证，编写操作说明。
4. 第 16–21 周：做两个故障案例和一份改进方案；练习把同一结果分别讲给工程师和非技术人员。
5. 第 22–26 周：根据 JD 选电源/接口/传感器细分，模拟客户澄清和技术会议；技术英语以 datasheet 与问题单为材料。

### 三级项目

**最小项目：运放选型与增益电路（2–3 周）。** 规格示例：已有低压电源下把 0–100 mV 信号放大至约 0–2 V，先判断单电源输入/输出范围和偏置。比较两款公开数据完整的器件，计算 offset、偏置电流、电阻误差、带宽和输出摆幅。验收：需求表与候选对比完整；nominal DC 增益误差教学目标 ≤1%，未覆盖的温漂/器件分布列为缺口。仿真需使用厂家合法宏模型或声明理想模型。故障诊断先查共模/输出摆幅、供电和模型引脚，再调电阻。

**核心项目：传感器前端 + 采集验证（6–8 周）。** 示例：0–100 mV 输入、标称增益 20、0–2 V 输出，目标带宽先设 10 kHz，并按现有 ADC 采样率和负载修订；增加抗混叠滤波、供电去耦和简单输入保护设计说明。验收：至少 5 个 DC 点和 3 个频率点，重复测量；增益/带宽/噪声/输出范围逐项对预算，所有超标有原因或下一步实验。实测受源/仪器限制时明确可分辨范围，不报低于设备能力的噪声。作品集包含 BOM、数据手册出处、仿真/实测分栏、一次故障复现和一页应用说明。

**进阶项目：模拟客户变更与故障支持（4–8 周）。** 给核心项目增加两项约束，例如输出驱动长线、输入有直流偏置或供电波动；先澄清条件，再给两套方案，比较精度/稳定性/功耗/成本与验证代价。量化验收：至少两种候选、每项关键要求可测试、两次故障最小复现；5 分钟演示后由同学用说明复现至少一个测试。未做真实 EMC 测试不得写“通过 EMC 认证”；BOM 价格只能注明实际查询日期与采购量，缺数据就留空。

### 面试、误区与降级

练习：客户说“噪声大”先确认哪些条件；推荐器件为什么不能只看 typical；改电路前如何保留原始问题；示波器看到振铃如何区分探测假象；在不可同时满足指标时如何说明取舍。误区：只介绍品牌型号、直接归咎客户、无测试就保证可用、把绝对最大额定当正常工作条件。

无 PCB/仪器：先完成需求、预算、合法宏模型仿真和故障注入，再争取校内现有板卡；这些能证明选型与分析，不能声称实物调试经验。无客户经验：用公开案例或模拟客户题，标注教学情境，不编企业客户故事。建议资源：R2、R3、R12、R14。

## 8. 怎样从这七条路线生成个人计划

1. 先做 2 周体验，每个候选方向仅 3–4 小时小任务；同时核对导师课题、现有工具和真实 JD。最多保留两条候选。
2. 主线只选一条，写出岗位关键词、P0 当前等级、距离 L2/L3 的证据缺口。相邻备选复用基础与项目，例如模拟→版图/应用，器件→PIE，测试→应用；不承诺无成本转岗。
3. 先做最小项目，再做一个核心项目，项目通过之前不叠加三门长课。进阶项目由资源与剩余求职时间决定。
4. 每周使用“本周指标—输入与版本—原始结果—失败诊断—下周最小动作”复盘；每 4 周由他人按证据复核等级。
5. 投递时用“做了什么、在什么条件、结果如何、证据在哪、尚缺什么”描述项目。不夸大工具熟练度，不把公共教程整体算个人原创，不把合成数据写成生产数据。
