# 学习方法与工程证据

## 一次学习的闭环

以90分钟为例：10分钟不看资料回忆上次内容；20分钟阅读一个知识点；35分钟完成手算/代码/仿真/数据任务；15分钟改变一个条件并预测结果；10分钟记录误差、失败与下一步。60分钟任务按比例缩小。阅读与动手可按内容调整，但不能一直看课不产出。

“学反馈”应改写为：先画环路和定义符号；推导一阶闭环；在仿真中扫补偿参数；预测带宽与相位变化；对比结果；解释不符合预测的原因。数字/工艺路线同样采用“先预测→再运行→解释差异”。

## 任务卡示例

**任务 A1-W2-01：共源级工作点和小信号。** 前置为MOS工作区、电阻/电容和基本仿真。用资源库中的课程与仿真器官方文档阅读DC/AC相关内容。预计2小时。建立合法教学模型电路，记录模型来源；计算近似工作点与增益；运行DC与AC；改变偏置；比较理论与仿真。产物为网表/原理图、模型来源、参数表和结果图。验收为能说明工作区、增益符号、变化方向与偏差来源，而非只交截图。若失败，按连接/参考地→参数单位→偏置→分析配置→模型适用范围检查。没有商业PDK时把成果命名为教学模型实验。

**任务 D2-W3-01：FIFO边界测试。** 前置为队列、时钟、复位和基本HDL。预计3小时。先定义满/空、同时读写和复位语义；建立参考队列；测试深度边界与指针回卷；人为注入一个错误；保存失败日志。验收为能重现错误、修复后回归通过，并解释哪些时序/CDC行为不在本项目范围。测试数量不是充分性证明，应把每个测试映射到规格点。

**任务 A4-W3-01：工艺数据实验设计。** 前置为均值、方差和对照概念。预计2小时。使用明确标为合成的数据建立两因子实验；画主效应和交互作用；检查重复、随机化及混杂因素；写不能外推的结论。验收为脚本可重跑、单位正确、区分相关与因果。合成数据不得写成晶圆厂实测。

## 三层项目模板

### 第一层 最小实验

先用2–8个任务小时完成一个入门微任务。参考库中的完整“最小项目”可能需要25–50小时或更长，日历周数按项目任务小时除以每周排定预算估算，并另计资源等待，不能统一承诺一到两周。输入、环境和输出保持小范围，优先验证能否运行、解释和重做。通过后再增加复杂度，避免初学者从完整SoC、PLL或全制程模型开始。

### 第二层 核心项目

持续6–12周或按时间预算延长。先用一页规格冻结功能/性能/条件，再分模块实现，再补异常/边界验证，最后整理证据。记录真实测试结论；冻结范围全部通过也如实保留。出现真实失败时复盘原因与修复；需要训练调试时，可另做明确标注的教学故障注入。安排一次有依据的对照修改，比较修改前后结果，不要求它必须来自真实缺陷。若项目来自课程或公共仓库，说明原始来源、复用内容与本人修改。

### 第三层 进阶扩展

仅在核心验收后加入：更复杂约束、自动化、统计、多条件比较、后仿或硬件测试等。进阶不是堆功能，而是回答一个新的工程问题。资源缺失时保留为待完成，不给自己加上没有取得的经验。

## 可复现目录

```text
project/
  README.md            # 目标、范围、复现入口
  spec.md              # 条件、单位、教学验收标准
  src/                 # 可公开代码/网表
  tests/               # 测试与检查脚本
  scripts/             # 数据处理与自动化
  results/             # 可公开的原始/派生结果
  evidence.md          # 每条结论对应文件与条件
  limitations.md       # 未验证事项与保密排除项
```

许可受限的PDK、库、公司数据、学校不允许公开的内容不要放入仓库；用合法说明、脱敏结果或仅公开自写脚本替代。不要上传密钥、账户、实验室内网路径。修改数据以匿名化时记录方法，并保持结论有效。

## 证据等级与表达

| 实际完成 | 可写的表述 | 不能写的表述 |
| --- | --- | --- |
| 读完教程并复现示例 | 复现某示例并解释参数影响 | 独立完成工业设计 |
| 教学MOS模型仿真 | 完成模型级DC/AC实验 | 完成某工艺签核 |
| 已授权PDK条件仿真 | 在所列模型/corner下达到自定指标 | 所有条件下稳定量产 |
| 真实DRC/LVS报告 | 指定视图与规则下检查结果为… | 仿真成功所以LVS通过 |
| 已流片且有测试结果 | 对该样片在所列条件完成测试 | 无数据声称全工艺达标 |
| 开源实现流程 | 在开源库与工具版本下复现实现 | 熟练掌握未用过的商业工具 |
| 合成或公开样例数据 | 基于合成/公开数据验证分析方法 | 真实生产良率提升 |

成绩和验收结果应由学生执行或可检查工具输出支持。AI可帮助读日志、设计测试、审阅解释，但学生要独立重做关键步骤并回答追问。

## 防止学习假进展

每周至少回答：这周新增哪条能力证据？不看教程还能做哪一步？最有价值的观察是什么（如遇真实失败或完成教学注入，分别注明）？如果换一个参数/边界，会发生什么？没有产物时缩小任务，而不是继续增加资料。每个阶段主教材至多1套，工具主文档1套，补充参考1–2项。
