SystemVerilog 是硬件设计与验证语言，UVM 是验证方法与框架；Python 测试可以训练验证思路，不能直接写成 UVM 经验。两个岗位的“好找工作”需要地区、届次和官方 JD 支持，目前没有足够匹配样本。2026-09-22 查看了[AMD 官方学生岗位入口](https://careers.amd.com/students/)，它只能提供查找渠道，不能证明你的目标地区机会或录用可能性。当前按通用能力框架试学，不混用海外实习或资深岗位条件。

**暂定画像。** 两年制研一、净6小时/周、稍会 Python、课程概念需要复测，无商业 EDA 和开发板。入学与毕业月份、导师方向、电脑系统、实习政策待确认；不会擅自套三年制时间表。数字基础、RTL、测试、排错都记“待测”，没有作品不等于已判定不适合。暂以 DV 为优先体验、FPGA 为备选，因为已有 Python 可复用；这是资源上的选择，不是终身定向。

第一周做六个短诊断，先答三项即可：①组合逻辑与寄存器差在哪；②画四位计数器从14到0的逐周期输出；③复位与使能同时有效时怎样规定优先级；④用 Python 写一个带断言的期望值函数；⑤解释时钟周期与计算延迟；⑥测试总显示通过，但故意把输出固定为0也通过，先查哪里。记录查资料程度，先补对应缺口。

**第一个月只交付一个“四位带复位/使能计数器及自检查测试”。** 每周排4.8小时、缓冲1.2小时；四周总净24小时，其中任务19.2小时、缓冲4.8小时，不额外塞 UVM、板卡采购或完整 UART。

| 周次 | 三项任务与小时 | 产物、验收、失败补救 |
| --- | --- | --- |
| W1 | 数字抽象/时序及诊断1.5h；写规格与 Python 参考模型2.5h；整理和复盘0.8h | 规定同步高有效复位优先，停使能保持，15后回0。交规格及6组输入/期望序列；手算与模型互验。写不出就先列十个时钟的表，再写函数。 |
| W2 | 寄存器与 RTL 语法1.5h；计数器 RTL 和最小仿真2.5h；记录环境与复盘0.8h | 用开源仿真器官方文档，保存代码、版本及一次复位/计数波形。能解释每个上升沿。安装排障最多1h，失败转为逐周期手算与代码审阅，明确“RTL未运行”，不耗尽本周。 |
| W3 | 自动检查与采样点1.5h；用 cocotb 或已有兼容环境写测试2.5h；缺陷记录0.8h | 覆盖复位、使能保持、回卷、连续计数、复位与使能同时有效；故意把回卷写错并抓住。正确版与故障版必须表现不同；查不到错先查比较语句、采样时刻和测试是否执行。 |
| W4 | 无提示改参数复测1.5h；同一模块的 FPGA 映射体验与修补2.5h；选方向复盘0.8h | 将宽度改为3位再测，估算寄存器数，画板级“时钟—复位—观察端口”框图。列出还缺器件型号、引脚及实现工具哪些信息。无板不填实测；如果前周没跑通，先完成最小重跑，映射只保留纸面。 |

输入资源限于[MIT 6.004 的组合逻辑、时序逻辑主题](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/)及[Verilator 官方入门](https://verilator.org/guide/latest/)；到 W3 再查[cocotb 官方文档](https://docs.cocotb.org/en/stable/)。入口已核查，具体安装依电脑和版本确定；不预设你会终端或已经装好兼容环境。Python 模型支路能继续练规格和检查，不能替代 HDL 仿真、综合、时序或板级证据。

技能账本按“技能—当前证据—等级—目标—依赖—任务—验收—复测”记录：数字基础→W1→L1；RTL→时序基础→W2/W4→L2；自动检查→可运行 RTL→W3/W4→L2；故障定位→自检→W3→L2。当前全部待测，第28天复测后更新。这里 L1 指能解释，L2 指能按文档完成并解释，独立实现、调试、复现后才讨论 L3。

最小项目就是本月计数器；主线确定后，核心项目可升级到单时钟 FIFO 边界验证，进阶再考虑总线验证或 FPGA 上板，二选一。核心项目须保存规格、版本、原始日志、检查方法、一次故障注入、个人贡献与复现说明。首月面试练三问：为何这些用例对应规格？采样时刻错了会怎样？测试能通过为何还可能漏错？没有通过的项目项保持“待做/未通过”。

第28天按兴趣、独立产出、课题复用和资源四项选主线，不计算录用概率。若更喜欢构造反例和查日志，继续 DV；若更喜欢接口及硬件行为，争取借板后补一次 FPGA 体验，再决定。第二个月才定核心项目，两年制同时核对毕业要求和目标招聘窗口。
