> 以下为发布前虚构情境的模型生成示例，尚未由学生执行，不代表实际工程结果或录用效果。

你的主线可以定为**模拟 IC 设计，先做与传感器接口相关的放大器**；相邻备选是模拟版图，等你做过电路与布局体验后再判断。岗位首先需要下面六项能力。

| 能力 | 工作中解决什么 | 入门交付物与目标 |
| --- | --- | --- |
| P0 MOS、偏置、小信号 | 决定电流、工作区和增益 | 工作点手算与模型对照，L2 |
| P0 电流镜、差分对 | 搭建放大器基本单元 | 标出信号与偏置路径，L2 |
| P0 反馈、极点、稳定性 | 解释带宽、振铃及负载影响 | 简化模型与阶跃对照，L2 |
| P0 仿真与调试 | 建立测试、识别错误条件 | DC/AC/瞬态输入及日志，L2→L3 |
| P0 规格与边界验证 | 判断在什么条件下达标 | 指标—条件—结果表，L2 |
| P1 噪声、失配与版图意识 | 处理精度和寄生限制 | 一页预算、未验证项清单，L1→L2 |

L1 是能解释并手算，L2 是能按文档实验且解释结果，L3 是能独立实现、排错并复现。它们是学习目标。2026-09-22 查到的[NXP 苏州模拟设计实习样本](https://nxp.wd3.myworkdayjobs.com/en-US/careers/job/XMLNAME-2027-Intern---Analog-Design-Engineer_R-10064636)涉及原理图、仿真、版图、文档和协作；只有一份样本，地区也未与你确认，不能当成所有企业门槛。上表主要采用通用能力框架，后续补齐同地区、同阶段的3–5份 JD。

**你的起点与诊断。** 已知：2026年9月入学、三年制、学过模电和半导体物理、没有项目、导师做传感器接口。预计2029年毕业，具体月份、毕业要求和实习政策待确认。每周净12小时；学校有授权，但你的账户尚不可用。六项能力均记“待测”，工具操作不预设会用。

先做七个诊断点，今天只选前三个，注明是否查资料：①画 NMOS 工作区判据；②给定工作点，画共源级小信号图并估增益；③输出削顶时按顺序查什么；④电流镜为何需要输出电压余量；⑤画差分输入与共模输入；⑥用一阶 RC 解释极点与阶跃；⑦读一张带单位的波形，区分瞬态幅值比和小信号增益。不会的保留空白，再据此补课。

账本先这样建：前两项依赖电路基础，映射 W1–W3，交手算与工作点表；仿真依赖文件、网表和分析设置，映射 W1–W4，交输入及日志；规格映射 W4，交测试表；反馈和噪声等映射第5周以后。每项保留“当前证据未提供、等级待测、目标、任务、验收、复测日期”，第4周末更新，不能以看完课程升级。

**暂定90天。** 每周排9.5小时，留2.5小时缓冲，所有诊断、装工具和复盘都包含在内。

- 第1–4周：MOS→偏置→共源级，完成一个可重跑的最小实验；若工作点仍解释不清，延长本阶段。
- 第5–8周：电流镜→差分对→五管 OTA（运算跨导放大器），先冻结偏置、负载和输入范围，完成标称条件版本。
- 第9–12周：补反馈基础，改变负载和输入幅度，解释一个失败，整理报告并无提示重做；余下天数补测。账户可用后按学校流程迁移，重新核对器件及额定条件，不直接照搬教学模型结果。

第一学期完成基础和 OTA 核心证据；第二学期与导师商定传感器前端规格，把课题预算、仿真与课程成果合并。研二深化项目并按获准实习时间准备，研三围绕实际招聘窗口和毕业收尾；招聘日期届时查官方发布。

前四周每周最多三项主要任务，表内均为排定时间：

| 周次 | 输入、任务与小时 | 产物、验收与补救 |
| --- | --- | --- |
| W1 | 诊断与 MOS 补课3h；账户申请及工具入门4.5h；整理与复盘2h | 用学校入门文档；账户未到用 ngspice 官方教程做分压器和 RC。交手算、网表、日志，能解释节点与单位。安装卡住1h即记录错误，余时做手算，不继续耗整周。 |
| W2 | 小信号与偏置3h；单管 DC 扫描4.5h；对照复盘2h | 选有明确来源的教学模型，记录参数与工作区，预测再扫三个偏置。趋势不符先查引脚、单位和模型条件；环境仍不可用则交解析曲线，标“待仿真”。 |
| W3 | 共源级手算2.5h；DC/AC及小信号瞬态5h；解释误差2h | 交增益与工作点对照。明确手算近似，AC与小信号瞬态应合理一致；削顶先减激励，再检查偏置与摆幅。 |
| W4 | 换负载无提示复测3h；补缺口及失败复现4.5h；报告与课题对齐2h | 从新目录重跑，讲清一次异常，写下月规格。未通过就缩小为共源级，推迟差分对。 |

主课只选[MIT 6.012 的 MOS、小信号、放大器主题](https://ocw.mit.edu/courses/6-012-microelectronic-devices-and-circuits-fall-2009/)；工具未就绪时读[ngspice 入门第3–5节](https://ngspice.sourceforge.io/ngspice-tutorial.html)，先学工作点、瞬态和 AC。以上入口已核查，安装和实验尚需你执行。

项目分三级：最小为共源级；核心为服务传感器接口的五管 OTA；进阶再选两级补偿或版图后仿之一。核心教学目标暂设标称增益≥30dB、负反馈可工作、输入不削顶范围可说明，模型和预算确定后再冻结，未达标也保留结果。保存规格、版本、输入、原始结果、测试矩阵、失败案例、个人贡献和复现步骤；每个条件分别判定。面试练三问：偏置为何这样选？负载增大改变什么？一次失败如何定位？没有检查器报告不写 LVS，没有实物不写流片。

**下一次75分钟**：10分钟画共源级，25分钟做前三个诊断，25分钟补一个工作区缺口，15分钟保存推导与未知项，计入 W1。七天后用实耗、产物和阻塞复盘。后续只需补三组信息：毕业与实习限制；意向城市和接口兴趣；电脑系统、编程基础及账户预计开通时间。暂时没有答案也按 W1 开始。
